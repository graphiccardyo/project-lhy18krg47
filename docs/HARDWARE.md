# 하드웨어

## 구성

| 부품 | 역할 | 비고 |
|---|---|---|
| Arduino Uno R3 | 제어기 (센서 200 Hz, 제어 100 Hz) | 시리얼 250000 baud, USB 전원 |
| L298N 모듈 | DC 모터 구동 | ENA PWM ≈ 980 Hz (D5, Timer0) |
| DC 모터 + 프로펠러 | 추력 → 진자 토크 | 별도 12 V 전원 |
| MPU6050 (GY-521) | 각도·각속도 측정 | 진자 막대에 고정, 회전축 = 센서 Z (부호 −) |
| 12 V 전원 | 모터 전원 | **전압이 바뀌면 플랜트 이득이 바뀜** (아래 참고) |

## 배선

| 우노 / 전원 | L298N | 비고 |
|---|---|---|
| D5 | ENA | **ENA 점퍼 제거**. 리셋 중에도 LOW를 유지하려면 ENA–GND에 10 kΩ |
| D7 | IN1 | |
| D8 | IN2 | |
| GND, 12 V 전원 − | GND | 공통 접지 |
| 12 V 전원 + | 모터 전원 입력 (+12V / VS) | 모터 전류를 USB/우노 5 V에서 공급하지 않음 |
| 우노 5 V | 5 V 로직 입력 | **5V-EN 점퍼를 제거한 뒤** 연결 (모듈마다 다르니 확인) |
| — | OUT1, OUT2 | 모터 두 선 |

| 우노 | MPU6050 (GY-521) |
|---|---|
| 3.3 V | VCC |
| GND | GND |
| A4 (= SDA, AREF 옆 핀과 같음) | SDA |
| A5 (= SCL) | SCL |

- I²C 풀업은 모듈(3.3 V) 것을 씁니다. 펌웨어가 우노 내부 5 V 풀업을 끕니다.
- **SDA/SCL이 바뀌면** `IMU ERROR NOT_FOUND no_ack`가 나옵니다(2026-11-06에 실제로 있었음). 고치면 재업로드 없이 1초 안에 다시 연결됩니다.
- 정회전(IN1 = H, IN2 = L)이 추력 방향입니다. 역추력(음수 PWM)은 기본 금지입니다.
- 배선은 전원을 끈 상태에서 하세요.

## 센서 장착과 축

- 센서는 진자 막대에 단단히 고정합니다. 현재 장착에서는 **피벗 축이 센서 Z**이고, 추력 방향이 +가 되도록 부호는 **−**입니다(`AXIS Z -`). 장착을 바꾸면 UI ①의 **자동 감지**로 다시 정하세요.
- θ = 0은 모터를 끈 채 매달린 정지 자세입니다(`ZERO`). 피벗 마찰 때문에 정지 위치가 매번 ±1–5° 다를 수 있으니, 실험 직전에 영점을 잡으세요.

## 진동 (중요)

2026-11-06 첫 실험에서 프로펠러 진동이 가속도계를 완전히 덮어 데이터를 쓸 수 없었습니다([RESULTS.md](RESULTS.md#1-첫-실험-진동-오염)).
- 펌웨어 대책: ±16 g / ±2000 °/s, DLPF 21 Hz, β 0.02, 가속도 저역통과 + 게이팅.
- 그래도 자이로에는 약 40–48 Hz, σ 25–35 °/s의 진동이 남아 있습니다.
- **권장 기계 조치**: 센서와 막대 사이에 고무·폼 절연, 프로펠러 균형 맞추기, 모터 마운트 조이기.
- UI 상단의 **게이트 %**(모터를 켠 상태에서 50% 이하 권장)와 **포화**(항상 0이어야 함)로 상태를 확인합니다.
- 식별된 **3.47 Hz 구조 공진**(막대·마운트 굽힘으로 추정)이 폐루프 이득을 제한합니다. 기계적으로 강성을 높이면 공진이 위로 올라가 제어가 쉬워집니다.

## 전원 전압과 이득

입력이 PWM(듀티)이므로 실제 모터 전압 = 듀티 × 전원 전압입니다. 2026-11-06 세션에서는 같은 PWM 150의 정착 각도가 20분 동안 23° → 19°로 줄었고, 이득 K는 0.21 → 0.12로 줄었습니다. 전원 전압 강하나 모터 발열 때문으로 추정합니다.
- 실험 전후에 부하 상태의 모터 전원 전압을 기록하세요.
- 배터리라면 안정화 전원장치를 권장합니다.
- 폐루프 설계는 K 0.12–0.21 전체에서 안정하도록 했습니다([analysis/pid_design/REPORT.md](../analysis/pid_design/REPORT.md)).
