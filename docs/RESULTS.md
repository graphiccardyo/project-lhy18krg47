|---|---|---|

| 주 동특성 | 1차 지연 T = 0.328 s (극점 −3.0 rad/s) + 지연 16 ms, **과감쇠** (진자형 오버슈트 없음) | 스텝·주파수응답 |
| 구조 공진 | **3.47 Hz, ζ = 0.12** (위상 −180° 교차 3.38 Hz) | run3 스윕 0.1–7/10 Hz |

```
G(s) = K · e^(−0.016 s) / (0.328 s + 1) · 21.8² / (s² + 5.37 s + 21.8²)     [deg/PWM]
MATLAB:  G = tf(K*21.8^2, conv([0.328 1], [1 5.37 21.8^2]), 'InputDelay', 0.016);
```

## 1. 첫 실험: 진동 오염

[data/20261106](../data/20261106/analysis/REPORT.md) — 계단 2회, 스텝, 스윕 (β 0.301, DLPF 94 Hz, ±4 g / ±500 °/s)

- 프로펠러 진동 때문에 θ<sub>acc</sub>가 ±150° 범위로 흔들렸고, 가속도 비중이 큰 Madgwick θ는 실제 자세에서 11–92° 떠내려갔습니다.
- 자이로도 센서 내부에서 포화된 것으로 보입니다. 같은 계단 시험 2회가 PWM 250에서 55°와 112°로 달랐습니다.
- 스텝·스윕 SNR이 0.5–5여서 어떤 모델도 교차검증을 통과하지 못했습니다. **이 데이터로 만든 잠정 모델은 폐기**했습니다.
- 대책으로 펌웨어를 바꿨습니다: ±16 g / ±2000 °/s, DLPF 21 Hz, β 0.02, 가속도 5 Hz 저역통과 + |a| 게이팅, 게이트·포화 지표.

## 2. 진동 대책 후 (run2)

[data/20261106_run2](../data/20261106_run2/analysis/REPORT.md) — 계단·스텝·스윕(±12, 0.1–3 Hz) 각 2회

- θ<sub>acc</sub> σ가 22–27°로 줄었고, Madgwick θ와 ∫ω의 차이 중앙값은 0.8°입니다. 반복 실험 상관은 0.87–0.95입니다.
- 정적 특성이 매끄럽고 단조로워졌습니다. 스텝 응답은 약 1 s 안에 오버슈트 없이 정착합니다.
- 1차 + 지연 모델의 교차검증 적합도는 46%였습니다(잡음 한계 약 65%). 2 Hz 위에서 이득이 다시 오르는 현상을 발견했습니다.

## 3. 공진 확인 · 최종 모델 (run3)

[data/20261106_run3](../data/20261106_run3/analysis/REPORT.md) — 스윕 ±12 (0.1–10 Hz) ×2, ±25 (0.1–7 Hz) ×2

- 진폭 ±25에서 SNR이 25로 올라 지금까지 가장 좋은 데이터입니다. 잡음 한계 적합도는 80%입니다.
- **3.47 Hz 구조 공진**을 확인했습니다. 1차 모델보다 이득이 약 3배 크고, 위상이 180° 떨어집니다.
- 공진을 포함한 모델은 추정 데이터(±25)에서 79%, 다른 모든 기록에서 각자의 잡음 한계 근처까지 맞습니다(K만 기록별로 조정한 경우).
- **K가 시간에 따라 감소했습니다**: 14:18 0.19–0.21 → 14:20 0.155 → 14:38 0.12–0.14. 같은 PWM에서 각도도 3° 줄었습니다. 전원 전압 강하나 발열을 의심합니다.
- 0.12 Hz 미만의 위상은 Madgwick과 자이로 적분이 서로 달라 신뢰하지 않습니다.

## 4. PID 설계 (목표 4–6)

[analysis/pid_design/REPORT.md](../analysis/pid_design/REPORT.md) — K ∈ {0.12, 0.15, 0.21} × 공진 ±10%, 최대 감도 Ms ≤ 1.6 기준

| 설계 | Kp | Ki | Kd | 상승 | 오버슈트 | 정상오차 | 최악 Ms |
|---|---|---|---|---|---|---|---|
| P (목표 4) | 3.70 | 0 | 0 | 0.42 s | 1% | 64% | 2.0 |
| PI | 2.76 | 8.40 | 0 | 1.63 s | 0% | 0 | 1.6 |
| **PI + 노치** | 7.85 | 23.9 | 0 | **0.40 s** | **0.5%** | 0 | 1.6 |

- 이득을 제한하는 것은 **3.5 Hz 구조 공진**입니다. 노치로 깎으면 같은 강인성에서 이득을 약 3배 올릴 수 있습니다.
- D 항은 거의 도움이 되지 않습니다. 플랜트가 이미 과감쇠라 개선할 것이 없고, 자이로 진동만 PWM으로 들어갑니다.
- Z-N의 Ku와 Tu는 진자가 아니라 구조 공진에서 정해지므로, 이득이 공격적으로 나와 강인성이 부족합니다. Z-N 방법의 한계를 보여 주는 결과입니다.
- 시뮬레이터(식별 모델)에서 권장 이득으로 스텝을 주면 상승 0.25 s, 오버슈트 3%입니다(시뮬레이터 이득 ≈ 0.2). 릴레이 시험으로는 Ku 8.27, Tu 0.300 s가 나와 모델 예측과 일치합니다.
