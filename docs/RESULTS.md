## 2. 플랜트 재식별과 PID 재설계 (11-15)

[data/20261115_run1](../data/20261115_run1/analysis/REPORT.md) (계단, 스텝 ×2, 스윕 ×2 + 30° 스윕, 릴레이) · [data/20261115_run2](../data/20261115_run2/analysis/REPORT.md) (재설계 이득 폐루프 스텝) · [data/20261115_run3](../data/20261115_run3/analysis/REPORT.md) (Z-N PID)

- **계기**: RL 실행들(11-14 rl1 → 11-15 rl8)의 폐루프 기록에서 추정한 공진이 2.59 → 2.40 Hz로 계속 내려갔고, 30 s 유지 시험에서 PID·RL 모두 2.1–2.5 Hz로 흔들렸습니다.
- **결과**: 공진 2.35 Hz(ζ 0.084), 한계 이득 4.87(11-13의 절반). 릴레이를 맞춤에 쓰지 않았는데 새 모델이 Tu 2%, Ku 3% 안으로 맞습니다. 11-13 모델은 이 스윕에서 주파수응답 오차 46%(새 모델 14%).
- 품질은 11-13보다 나쁩니다(θ<sub>acc</sub> σ 10–14°, 스윕 반복 SNR 4.3). 자이로 바이어스가 시험 시간 동안 쌓여 **각도 소스를 Madgwick θ로 고정**해야 했습니다(`aero_analyze.py --angle theta`).
- **재설계**: PI + 2.35 Hz 노치 4.30 / 13.3(K 0.12–0.23 × 공진 ±10%에서 최악 Ms 1.60). 11-13 권장값(PI 5.40 / 16.9 + 2.84 Hz 노치)은 새 플랜트에서 최악 Ms 3.3이라 쓰면 안 됩니다.
- **하드웨어 폐루프 스텝**(4.34 / 13.4): 상승 0.57–0.71 s, 지속 진동 없음, 유지 리플 σ 0.10–0.30°. 리플을 뺀 오버슈트 8–12%로 모델(6%)보다 큽니다. PID + 노치(Kd 0.067)는 상승 0.57 s·오버슈트 8%, Z-N PI 2.19 / 5.99는 상승 1.40–1.45 s.
- **Z-N PID(2.92 / 13.3 / 0.160, run3, 1회)**: 20° → 25°에서 발산하지 않지만 2.34 Hz 리플이 기록 내내 줄지 않고 남습니다(2 s 창 σ 0.34–0.68°, 유지 리플 σ 0.43°). 상승 0.72 s(모델 0.56 s), 리플을 뺀 오버슈트 4%. 모델 공칭 Ms 3.6, K 0.23(30° 등가)에서 불안정이라 30°는 시험하지 않았습니다. Ku·Tu가 구조 공진에서 정해져 공진 근처 여유가 작다는 Z-N의 한계를 11-13에 이어 다시 확인했습니다.
- **Z-N PID + 2.35 Hz 노치**(같은 이득, run3, 1회): 리플이 기록 내내 0.14–0.28°로 평평하고(유지 σ 0.24°, PI + 노치 수준), 유지 PWM σ 2.0 → 0.8, 상승 0.60 s(모델 0.58 s), 리플을 뺀 오버슈트 6%. 모델 Ms 1.18–1.28로 K 범위 전체에서 안정. 이득을 그대로 두고 공진에서의 루프 이득만 깎아 문제가 사라졌으므로, Z-N 이득의 여유 부족이 구조 공진 때문임이 직접 확인됐습니다.
- run2에서 Z-N PID를 의도한 기록 다섯 개는 보드에 **Kp 2.19로 적용**돼 있었습니다(이득 적용을 누르지 않음). 이 조합(2.19 / 13.3 / 0.16)은 상승 0.61–0.75 s, 30 s 유지에서 편향 ±0.01°, σ(e) 0.20°(20°) / 0.37°(25°)이고 오차 대부분이 2.3–2.6 Hz 리플입니다. 같은 Ki·Kd에서 Kp만 2.19 → 2.92로 올리면 리플이 가라앉지 않게 됩니다.
- 공진이 내려간 원인은 확인하지 않았지만 강성 저하(마운트·조인트 풀림, 모터 마모, 수축튜브)로 해석합니다. 모터 소리가 달라지고 진동이 커진 시기와 겹칩니다.
- **상수를 바꾼 곳**: `analysis/pid_design.py`·`aero_closedloop.py` 기본값, `lab/sim.js`(정적 지도·동특성), `lab/sysid.js`·`lab/app.js`(UI 모델 예측), `lab/index.html`(노치 기본 2.35 Hz), `rl/config.py`(가짜 보드 플랜트·도메인 랜덤화), `matlab/aero_pid_design.m`(문법만, 실행 안 함). 11-13 기록의 재현 명령에는 `--model …`을 붙였습니다.

### 자세 추정 IMU 문제와 대책

11-15 새벽, rl3 후반·rl4·rl7에서 Madgwick θ가 가속도계 각 θ<sub>acc</sub>에서 수십 도 떠내려갔습니다. 실험 UI 시험에도 해당하는 문제라 여기에 요약합니다(경위는 [RL_HISTORY.md D8](RL_HISTORY.md#d8-imu-자세-추정-감시와-보정)).

- **원인**: 처음에는 진동 정류(모터 가동 중에만 자이로 편향)로 봤지만, 정지 점검(`rl.imu_check`, 모터 끔)에서 **모터를 끈 상태에서도 진자 축 자이로 잔여 편향이 운전 온도에서 +0.57 °/s, 식은 뒤 −0.41 °/s**로 온도에 따라 약 1 °/s 흔들렸습니다. 펌웨어 Madgwick이 바로잡을 수 있는 각속도 편향은 약 2β(수평 두 축 공유)인데, β 0.004에서는 0.46 °/s라 이를 넘었습니다.
- **대책**(사용자 승인, `CFG BACKUP` 후): 따뜻할 때 `CAL`(정지 보정)을 다시 하고 **β를 0.004 → 0.01**(보정 예산 1.15 °/s)로 올렸습니다. β 0.01에서 같은 편향의 정지 간극은 60 s 동안 0.0°로 유지됩니다. β는 느린 표류만 바로잡으므로 식별 모델·PID 설계에는 영향이 없습니다.
- **기록 구분**: 11-15 rl8 이후 기록은 β 0.01, 그 전 11-13 이후 기록은 β 0.004입니다(CSV 머리줄 `beta=`). EEPROM 예비 영역(`CFG RESTORE`)에는 β 0.004 + 새 보정이 들어 있습니다.
- **감시**: 학습기는 모터 가동 중 θ − θ<sub>acc</sub> 10 s 이동평균 > 3°면 자동 일시정지, > 2°면 경고합니다. 세션 시작 전 `rl.imu_check`(1분)를 권장합니다.
- 기록 해석 주의: 11-14 rl3 후반(ep 60–)과 11-15 rl1의 "같은 PWM에 각도 3–5° 낮아짐"은 당시 과열에 의한 이득 변화로 봤지만, 같은 자이로 편향 표류가 섞였을 수 있습니다(원인 미확정).
