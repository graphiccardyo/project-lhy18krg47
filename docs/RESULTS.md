## 1. 기구 수정 후 개루프 재식별 (11-13 run1)

[data/20261113_run1](../data/20261113_run1/analysis/REPORT.md) — 계단 ×2, 스텝 ×2 (160 ± 12), 스윕 ×2 (160 ± 12, 0.1–8 Hz)

- 진동 지표가 4–5배 줄었습니다(θ<sub>acc</sub> σ 3–5°, 자이로 진동 6–7 °/s). 반복 쌍 SNR은 스텝 32, 스윕 10이고, 잡음 한계 적합도는 각각 83%, 70%입니다.
- **구조 공진이 3.47 → 2.84 Hz로 18% 내려갔습니다.** 11-06 모델로 이 스윕을 보면 주파수응답 오차가 55–59%입니다(새 모델 9%). 스윕이 8 Hz까지라 공진을 충분히 덮습니다.
- 스윕의 이득(0.13–0.145)과 스텝·계단의 이득(0.17–0.22)이 3분 안에서도 다릅니다. 11-06에 시간 변화와 섞여 있던 현상인데, 이번에 **수 초 단위의 느린 병렬 경로**(Ks 0.05, Tc 6 s)로 설명했습니다. 원인은 케이블 점탄성·피벗 크리프로 추정합니다.
- 최종 모델의 시간영역 적합도: 스윕 72–73%(잡음 한계 70%), 스텝 65–81%(한계 83%).

## 2. 폐루프 시험과 모델 검증 (11-13 run2·run3)

[data/20261113_run2](../data/20261113_run2/analysis/REPORT.md) (노치 2.85 Hz) · [data/20261113_run3](../data/20261113_run3/analysis/REPORT.md) (노치 없음)

- 펌웨어와 같은 `pidStep`(최소·최대 PWM 포함)과 새 모델로 각 기록을 재현했습니다(`analysis/aero_closedloop.py`).
- **손튜닝 PID**(프리셋 "PID-전달함수로부터"): θ 적합 93–94%, PWM 적합 92–93%. 상승시간 실측 1.45–1.51 s, 모델 1.59 s. 모델상 Ms 1.12, 위상 여유 74.5°, 이득 여유 20.8 dB(K 0.14). 9개 조합 최악은 Ms 1.21.
- **릴레이 (20°)**: Tu 0.370 s(모델 0.369 s), Ku 10.2(모델 10.9). 11-06 모델은 Tu 0.300 s로 예측해 어긋납니다. **릴레이 (30°)**: Ku 6.24 → 30°에서 이득이 약 1.6배(K ≈ 0.24).
- **Z-N PID**(6.125 / 33.1 / 0.283): 모델상 20°에서 Ms 3.4, 30°(K 0.24)에서 불안정. 실측도 30°에서 2.7 Hz 지속 진동. Z-N 이득이 공진에서 정해져 공격적이라는 결론이 하드웨어로 확인됐습니다.
- **PI + 2.85 Hz 노치**(4.5 / 13.5): θ 적합 90–91%, 상승 0.73 s.
- 두 기록(P 제어, Kd 없는 PI)에서 **케이블이 걸렸다 풀리는 충격**으로 보이는 15–25° 튐 + 2.7 Hz 울림이 기록당 4회 있었습니다. 시작 순간 PWM은 변하지 않았고, 모델상 두 제어기 모두 여유가 큽니다. 모델에는 없는 외란입니다.

## 4. (기구 수정 전) 첫 실험: 진동 오염

[data/20261106](../data/20261106/analysis/REPORT.md) — 계단 2회, 스텝, 스윕 (β 0.301, DLPF 94 Hz, ±4 g / ±500 °/s)

- 프로펠러 진동 때문에 θ<sub>acc</sub>가 ±150° 범위로 흔들렸고, 가속도 비중이 큰 Madgwick θ는 실제 자세에서 11–92° 떠내려갔습니다.
- 자이로도 센서 내부에서 포화된 것으로 보입니다. 같은 계단 시험 2회가 PWM 250에서 55°와 112°로 달랐습니다.
- 스텝·스윕 SNR이 0.5–5여서 어떤 모델도 교차검증을 통과하지 못했습니다. **이 데이터로 만든 잠정 모델은 폐기**했습니다.
- 대책으로 펌웨어를 바꿨습니다: ±16 g / ±2000 °/s, DLPF 21 Hz, β 0.02, 가속도 5 Hz 저역통과 + |a| 게이팅, 게이트·포화 지표.

## 6. (기구 수정 전) 공진 확인 · 11-06 모델 (run3)

[data/20261106_run3](../data/20261106_run3/analysis/REPORT.md) — 스윕 ±12 (0.1–10 Hz) ×2, ±25 (0.1–7 Hz) ×2

- 진폭 ±25에서 SNR이 25로 올라 지금까지 가장 좋은 데이터입니다. 잡음 한계 적합도는 80%입니다.
- **3.47 Hz 구조 공진**을 확인했습니다. 1차 모델보다 이득이 약 3배 크고, 위상이 180° 떨어집니다.
- 공진을 포함한 모델은 추정 데이터(±25)에서 79%, 다른 모든 기록에서 각자의 잡음 한계 근처까지 맞습니다(K만 기록별로 조정한 경우).
- **K가 시간에 따라 감소했습니다**: 14:18 0.19–0.21 → 14:20 0.155 → 14:38 0.12–0.14. 같은 PWM에서 각도도 3° 줄었습니다. 전원 전압 강하나 발열을 의심합니다.
- 0.12 Hz 미만의 위상은 Madgwick과 자이로 적분이 서로 달라 신뢰하지 않습니다.
