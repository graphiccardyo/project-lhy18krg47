# 실험 가이드

`Start-Lab.cmd` → **보드 연결** → COM 포트 선택 (Edge/Chrome, Web Serial). 하드웨어 없이 연습하려면 **시뮬레이터**를 누르세요. 시뮬레이터는 식별 모델로 만든 가상 진자라 실제 값과 다릅니다.

UI 탭: ① 센서·보정 · ② 수동 구동 · ③ 시험1 정적 특성 · ④ 시험2 동적 응답 · ⑤ 데이터·추정 · ⑥ 폐루프·PID.
오른쪽(좁은 화면에서는 아래)에 실시간 θ / θ<sub>acc</sub> / PWM / 기준 그래프, ω 그래프, 이벤트 로그가 있습니다.

> **입력 단위는 PWM(0–255)** 입니다. 듀티 %(= PWM/2.55)는 참고용입니다. 시리얼 속도는 250000 baud이고, 포트는 한 프로그램만 열 수 있습니다.

## 0. 실험 전 확인

1. 펌웨어가 최신인지 확인합니다. 연결 직후 로그에 `READY AEROPEND_LAB 2.0`과 `PIDCFG …`가 보여야 합니다. 업로드 방법은 [README](../README.md#빠른-시작)에 있습니다.
2. 상단 **IMU** 점이 초록인지 봅니다. 빨강이면 배선(SDA→A4, SCL→A5, VCC 3.3 V)을 확인하세요. 배선을 고치면 1초 안에 자동으로 다시 잡습니다.
3. **모터 전원 전압**을 기록해 두세요. 같은 PWM에서도 전압이 바뀌면 추력·이득이 바뀝니다(2026-11-06 실험에서 20분 동안 이득이 약 20% 감소).
4. ② 탭에서 **최대 PWM**(예: 210)과 **각도 한계**(시험 각도 + 15–20°)를 정하고 **한계·샘플링 적용**을 누릅니다.
5. 언제든 **정지 STOP**, Esc, Space로 바로 멈출 수 있습니다.

## ① 센서·보정

1. **회전축**: 진자 피벗 축과 같은 센서 축(X/Y/Z)과 부호를 고릅니다. 모르면 **자동 감지**를 누르고 3초 동안 진자를 손으로 흔드세요. 현재 장치는 **Z−**입니다.
2. **정지 보정 + 영점** (매 실험 직전 권장)
   - 모터를 끈 채 진자를 매달린 상태로 완전히 멈춘 뒤 누릅니다.
   - 3초 카운트다운 뒤 5초(1000샘플) 동안 **자이로 바이어스**를 구합니다. 정지해 있기만 하면 자세는 상관없습니다. 이어서 그 자세를 θ = 0으로 저장합니다.
   - 움직임(자이로 σ > 0.4 °/s, 가속도 σ > 0.03 g)이 있거나 |a|가 1 g ± 15%를 벗어나면 적용하지 않습니다.
   - 결과는 EEPROM에 저장되어 전원을 꺼도 유지됩니다.
3. **부호 확인**: 손으로 진자를 추력 방향으로 들었을 때 θ가 +로 커져야 합니다. 아니면 **부호 반전**을 누르세요.
4. **필터** (기본값 권장)
   - Madgwick β = 0.02(자이로 위주), MPU6050 DLPF = 4 (21 Hz). 진동이 심하면 DLPF를 5 (10 Hz)로 바꿉니다.
   - 실시간 그래프에서 회색 θ<sub>acc</sub>(가속도만으로 구한 각도)와 파란 θ(Madgwick)를 비교하세요. 모터를 끈 정지 상태에서는 몇 도 안에서 일치해야 합니다.
   - 상단 수신율 칸의 **게이트 %**와 **포화** 지표를 봅니다. 모터를 켠 채 게이트가 계속 50%를 넘거나 포화가 0이 아니면, 센서 진동 절연과 프로펠러 균형부터 손보세요. 자세한 내용은 [HARDWARE.md](HARDWARE.md)에 있습니다.
5. **센서를 교체했을 때**(④ 아래 접힌 메뉴): **수평면 보정**(`CAL FLAT`, +Z를 위로 해서 평평하게)으로 가속도 오프셋을 다시 측정하거나 직접 입력합니다. 기본 오프셋은 [data/calibration/mpu6050-calibration-20261031.json](../data/calibration/mpu6050-calibration-20261031.json)의 값입니다.

## ② 수동 구동

- 슬라이더 또는 숫자로 PWM을 직접 줍니다. **슬라이더 즉시 출력**을 켜면 움직이는 대로 반영됩니다.
- **수동 기록**: 원하는 구간을 CSV로 저장합니다.
- **샘플링**: 200 / 100 / 50 Hz 중에서 고르며, 식별과 제어에는 **100 Hz**를 권장합니다.
- **벤치 모드(드라이런)**: 센서나 모터 없이 시험 로직만 확인할 때 씁니다. PWM 값은 기록되지만 **모터 핀은 항상 LOW**입니다. 재부팅하면 꺼집니다.

## ③ 시험 1 — 정적 특성 (목표 1)

- PWM을 계단식으로 올리며 각 계단 후반(기본 50%)의 평균 각도를 표·그래프로 보여 줍니다.
- 권장 조건: **50 → 250, 10씩, 계단 3 s**, 2회 반복.
- 결과로 사각지대, 국소 이득 dθ/dPWM, `sinθ ≈ k(PWM − PWM_dz)` 회귀를 얻습니다. 표의 행을 클릭하면 그 PWM이 시험 2의 운전점이 됩니다.
- 표준편차 σ가 크면 아직 흔들리는 중이므로 계단 시간을 늘리세요.

## ④ 시험 2 — 동적 응답 (목표 2)

운전점 PWM₀에서 **정착(pre, 12 s)** 시킨 뒤 가진합니다. 가진 신호는 펌웨어가 샘플 주기에 맞춰 생성하므로 PC 타이밍의 영향을 받지 않습니다.

| 가진 | 권장 조건 (2026-11-06 결과 기준) | 비고 |
|---|---|---|
| 스텝 | PWM 150 → 162 → 150, 10 s / 10 s | 끝나면 K·오버슈트·정착 등 표시 |
| 스윕 사인 | **PWM 150 ± 25, 0.1 → 7 Hz 로그, 60 s** | SNR 25. ±12로는 SNR 6–7 |
| PRBS | PWM 150 ± 25, 비트 ≈ 1/(3·f<sub>max</sub>) | 9비트 LFSR |

같은 시험을 **2회 이상 반복**하세요. 반복 기록끼리의 차이로 잡음 수준과 재현성을 계산할 수 있어, 별도 검증 데이터 없이도 검증이 됩니다(`analysis/aero_analyze.py`). 시험이 끝나면 CSV가 다운로드 폴더에 자동 저장됩니다. 팀 데이터는 `data/<날짜>_runN/`에 올려 주세요([data/README.md](../data/README.md)).

## ⑤ 데이터·추정 (목표 3)

- **브라우저 빠른 확인**: 추정 기록과 검증 기록을 골라 2차 모델(ARX → Steiglitz–McBride)을 맞추고 검증 적합도를 보여 줍니다. 현장 확인용입니다.
- **MATLAB (보고서용)**:
  ```matlab
  addpath matlab
  T = aero_static_map('data/.../aero_STAIR_....csv');                          % 시험 1
  [G, info] = aero_sysid('aero_CHIRP_....csv', 'aero_STEP_....csv');           % 추정 → 검증
  [G, info] = aero_sysid_all({'aero_STEP_...csv','aero_CHIRP_...csv'});        % 검증 데이터 없이: 합동 추정 + 실험 간 교차검증
  ```
  System Identification App을 쓸 때는 `[ze,ope]=aero_iddata(aero_load(est)); systemIdentification`으로 시작해 Import → Object로 `ze`를 불러옵니다.
- **Python (진단·공진 포함 모델)**:
  ```bash
  python analysis/aero_analyze.py data/20261106_run3      # 품질·재현성·SNR·정적 특성·교차검증
  python analysis/aero_freqresp.py data/20261106_run3     # CHIRP 주파수응답
  python analysis/aero_model_fit.py --est <CHIRP csv들> --val <다른 기록들>   # 공진 포함 모델 맞춤 + 검증
  ```
- 모델은 **운전점 주변 소신호 모델**(Δθ/ΔPWM)입니다. 정착 구간 후반의 평균을 운전점으로 빼고, 가진 직전 1 s부터 사용합니다.

## ⑥ 폐루프·PID (목표 4–6)

설계 근거는 [analysis/pid_design/REPORT.md](../analysis/pid_design/REPORT.md)에 있습니다.

제어기(펌웨어, Ts = 10 ms): `u = ff + Kp·e + Ki·∫e − Kd·ω_f`
- e = 기준 − θ입니다. D는 자이로 각속도를 10 Hz로 저역통과해 측정값에 적용하므로 기준이 바뀌어도 킥이 없습니다.
- 출력은 노치(선택) → 포화 [0, 최대 PWM] 순서로 처리하고, 포화 방향으로는 적분을 멈춥니다(anti-windup).
- 이득은 **전원을 켤 때마다 0**이 됩니다. 연결 후 **이득 적용**을 누르세요.

1. **프리셋**을 고르고 **불러오기 → 이득 적용**을 누릅니다. 입력란 아래에 모델 예측(K = 0.12 / 0.15 / 0.21)이 바로 표시됩니다.
   | 프리셋 | 용도 |
   |---|---|
   | P (Kp 3.7) | 목표 4: 폐루프 스텝. 정상상태 오차가 크게 남는 것(예측 ≈ 64%)을 보여 줌 |
   | PI | 노치 없는 기준선 (느림) |
   | **PI + 노치** | **권장** (상승 ≈ 0.4 s, 오버슈트 < 1%) |
   | PID + 노치 | PID 비교용 (PI와 거의 같음, D는 잡음만 더함) |
   | Z-N PID / + 노치 | 목표 6 비교용. 노치 없는 Z-N PID는 일부 조건에서 불안정할 수 있음 |
2. **ff**(피드포워드)는 기준 각도의 평형 PWM 근처로 둡니다(20°면 약 145–150).
3. **기준 유지**: 원하는 각도를 유지합니다. STOP으로 해제합니다.
4. **폐루프 스텝 시험**: 기준 r0 유지 → r1 → r0 (예: 20° → 25°, 8 s / 8 s / 6 s).
   - 끝나면 상승시간·오버슈트·정착(±5%)·정상오차·PWM 범위·포화율을 표시하고, **측정과 모델 예측**(K = 0.12 / 0.21)을 겹쳐 그립니다.
5. **릴레이 시험 (Z-N 한계이득)**
   - 먼저 위 이득(적분 포함, 예: PI + 노치)으로 기준을 유지하며 평형 PWM을 찾고, 그다음 출력을 중심 ± d로 뒤집어 지속 진동을 만듭니다.
   - Ku = 4d/(π√(a² − ε²)), Tu = 진동 주기로 계산하고, **Z-N P/PI/PID** 버튼으로 이득을 입력란에 불러옵니다.
   - 권장: d = 10–15 PWM, 히스테리시스 0.1°, 유지 8 s, 릴레이 10 s. 예상값은 Tu ≈ 0.30 s, Ku ≈ 8–12입니다.
   - **이 장치에서는 진동이 3.5 Hz 구조 공진에서 일어나므로** Z-N 이득이 공격적으로 나옵니다. 처음에는 각도 한계를 낮게 두세요.

폐루프 CSV에는 `ref_deg` 열과 `# pid …` 줄(사용한 이득)이 함께 저장됩니다.

## 안전 장치

- 통신이 1초 이상 끊기면 정지합니다(UI는 0.25 s마다 PING).
- 각도 한계 초과, IMU 읽기 실패 시 정지합니다(`EVT ABORT …`).
- 최대 PWM 제한이 있고, 역추력은 기본 금지입니다.
- 하드웨어 워치독(0.5 s): 펌웨어가 멈추면 리셋되고 출력은 LOW가 됩니다.
- **정지 STOP** / Esc / Space로 언제든 멈출 수 있습니다.

## 문제 해결

| 증상 | 원인·조치 |
|---|---|
| 포트를 열 수 없음 | 다른 페이지·시리얼 모니터·업로드가 포트를 쓰는 중. 닫고 다시 연결 |
| `IMU ERROR NOT_FOUND no_ack` | SDA/SCL 바뀜·헐거움, VCC 3.3 V 확인. 고치면 자동 재연결 |
| 모터를 켜면 θ가 천천히 떠내려감 | 진동이 가속도에 섞임 → β를 낮게(0.02), DLPF 4–5, 게이트 % 확인, 센서 진동 절연 |
| 포화 경고 | 진동이 ±16 g / ±2000 °/s를 넘음 → 센서 장착을 바꿔야 함. 그 구간 데이터는 신뢰하기 어려움 |
| 시작 각도가 0이 아님 (2–5°) | 영점을 다시 잡지 않았거나 피벗 마찰. 실험 직전에 정지 보정 + 영점 |
| 같은 PWM인데 각도가 날마다 다름 | 모터 전원 전압 확인 (배터리 소모·발열) |
| `ERR BUSY` | 다른 시험·보정·폐루프 유지 중. STOP 후 다시 |

## 알려진 한계

- 가속도 오프셋은 이전 저장값(±2 g 설정에서 측정)을 그대로 씁니다. 정지 상태 |a|가 1.055 g로 나왔으므로, 큰 각도에서 수 도의 절대 오차가 있을 수 있습니다. 소신호 식별과 제어에는 영향이 작습니다.
- 진자가 흔들릴 때 θ<sub>acc</sub>는 원심·접선 가속도 때문에 부정확합니다. 그래서 θ는 자이로 위주(β 0.02)로 구합니다.
- 피벗 마찰 때문에 정지 위치가 ±1–1.5° 바뀌는 일이 있습니다. 동특성 분석에서는 구간 평균을 빼서 처리합니다.
