# MPU6050 읽기 실험

현재 우노에는 MPU6050 전용 스케치가 올라가 있습니다. 모터용 12V는 분리한 상태로 사용합니다.

`Start-MPU6050.cmd`를 더블클릭하면 COM4에 자동 연결하여 가속도(g), 각속도(°/s), 센서 내부 온도(°C)를 보여줍니다. 기본 출력은 20 Hz이며 원시값과 변환값은 `logs/mpu6050-*.csv`에 함께 저장됩니다. Arduino IDE 시리얼 모니터로 볼 때는 115200 baud를 사용합니다. 포트는 한 프로그램만 사용할 수 있습니다.

우노 R3의 AREF 옆 SDA/SCL은 각각 A4/A5와 같은 I²C 선입니다. 현재 연결은 GY-521 VCC→3.3V, GND→GND, SDA→SDA, SCL→SCL입니다. 스케치는 외부 모듈의 풀업을 사용하며 우노의 내부 5V 풀업은 끕니다.

I²C 주소 0x68/0x69에서 식별 레지스터 0x75의 값 0x68을 확인하고, ±2g / ±250°/s 범위를 설정·재확인한 뒤 14바이트를 연속해서 읽습니다. 가속도에는 중력이 포함되며, 자이로는 회전 각도가 아닌 각속도입니다. 영점·스케일 보정은 하지 않습니다. 온도는 센서 칩 내부 온도입니다.

센서 코드: `firmware/uno_mpu6050/uno_mpu6050.ino`

기존 모터 코드와 PC 조절기는 보존되어 있습니다. 다시 모터를 사용할 때는 `firmware/uno_l298n/uno_l298n.ino`를 우노에 재업로드해야 합니다.

참고: [Arduino Uno 핀 설명](https://github.com/arduino/docs-content/blob/main/content/hardware/uno/boards/uno-rev3/datasheet/datasheet.md), [Adafruit MPU6050 변환식](https://github.com/adafruit/Adafruit_MPU6050/blob/master/Adafruit_MPU6050.cpp).
