# MPU6050 보정 전후 비교

현재 우노에는 MPU6050 전용 스케치가 올라가 있습니다. 모터용 12V는 분리한 상태로 사용합니다.

`Start-MPU6050.cmd` 또는 `Start-MPU6050-Compare.cmd`를 더블클릭하면 COM4에 자동 연결합니다. MPU6050_light 1.2.1 라이브러리를 사용하여 같은 샘플의 보정 전·후 가속도(g)와 각속도(°/s), 차이를 나란히 표시합니다. 선택한 축은 최근 15초 그래프로 비교할 수 있습니다. 내부 온도는 보정 대상에 포함하지 않습니다.

수동 보정 방법:

1. 센서 기판을 수평으로, 부품이 있는 면과 +Z 방향이 위로 오도록 놓습니다.
2. 수평·정지 확인란을 체크하고 **보정 시작**을 누릅니다. 3초 준비 시간 뒤 약 3~5초 동안 움직이지 마세요. 준비 시간에는 취소할 수 있습니다.
3. 성공하면 보정 후 기준값은 가속도 (0,0,+1) g, 각속도 (0,0,0) °/s입니다. 움직임·자세·통신 이상이 감지되면 적용하지 않고 기존 오프셋을 유지합니다. **보정 해제**로 미보정 상태를 비교할 수 있습니다.

자동 보정은 하지 않습니다. 라이브러리의 `calcOffsets(true,true)`가 수행하는 500샘플 단일 자세 오프셋 보정이며, 중력은 남겨 둡니다. 스케일·축 오정렬·온도 보정이나 6면 정밀 교정을 수행하지 않습니다. 보정값은 RAM에만 있으며 USB 재연결·우노 리셋 시 초기화됩니다.

20 Hz의 전·후 값은 `logs/mpu6050-compare-*.csv`, 보정 이벤트와 오프셋은 같은 파일명의 `.events.log`에 저장됩니다. `cal_id=0`은 미보정 상태입니다. Arduino IDE 시리얼 모니터는 115200 baud이며 포트는 한 프로그램만 사용할 수 있습니다.

우노 R3의 AREF 옆 SDA/SCL은 각각 A4/A5와 같은 I²C 선입니다. 현재 연결은 GY-521 VCC→3.3V, GND→GND, SDA→SDA, SCL→SCL입니다. 스케치는 외부 모듈의 풀업을 사용하며 우노의 내부 5V 풀업은 끕니다.

I²C 주소 0x68/0x69에서 식별 레지스터 0x75의 값 0x68을 확인하고 ±2g / ±250°/s 범위를 설정·재확인합니다. 라이브러리의 같은 14바이트 샘플에서 보정 후 값과 현재 오프셋을 얻어 보정 전 값을 복원하므로, 두 열은 서로 다른 시점의 측정값이 아닙니다. 자이로 값은 회전 각도가 아닌 각속도이며, 온도는 센서 칩 내부 온도입니다.

현재 센서 코드: `firmware/uno_mpu6050_compare/uno_mpu6050_compare.ino`

이전 미보정 전용 코드: `firmware/uno_mpu6050/uno_mpu6050.ino` (보존)

기존 모터 코드와 PC 조절기는 보존되어 있습니다. 다시 모터를 사용할 때는 `firmware/uno_l298n/uno_l298n.ino`를 우노에 재업로드해야 합니다.

라이브러리: [MPU6050_light](https://github.com/rfetick/MPU6050_light), [보정 구현](https://github.com/rfetick/MPU6050_light/blob/master/src/MPU6050_light.cpp). 프로젝트 전용 설치 경로는 `.tools/arduino-user/libraries/MPU6050_light`이며 버전과 소스 해시는 `library-lock.json`에 기록했습니다.
