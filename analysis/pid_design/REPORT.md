# PID 설계 (목표 4–6) — 식별 모델 기반

재현: `python analysis/pid_design.py` → `summary.txt`, `step_responses.png`, `loop_shapes.png`
MATLAB: `aero_pid_design` (같은 플랜트·이득으로 margin / stepinfo)

## 플랜트

`data/20261106_run3/analysis/REPORT.md`에서 확정한 모델을 씁니다(PWM ≈ 150, θ ≈ 20°, 소신호).

```
P(s) = K e^(−0.016 s) / (0.328 s + 1) · 21.8² / (s² + 5.37 s + 21.8²)    [deg/PWM]
```

- K는 세션 중 **0.12–0.21**로 변했습니다(전원·발열 추정). 공칭값은 0.15입니다.
- **3.47 Hz 구조 공진**(ζ≈0.12)이 있어서, 위상이 −180°가 되는 곳이 진자 대역이 아니라 이 공진입니다.
- 강인성은 K ∈ {0.12, 0.15, 0.21} × 공진 주파수 ±10%, 즉 9개 조합의 최악값으로 평가했습니다.

## 제어기 구조 (펌웨어 `pidStep`과 동일)

```
u = ff + Kp·e + Ki·∫e dt − Kd·ω_f        e = 기준 − θ,  Ts = 10 ms
```
- **D는 자이로 각속도**(10 Hz 저역통과)를 **측정값에** 적용합니다. 기준이 바뀌어도 미분 킥이 없고, θ를 미분하지 않아 잡음이 적습니다.
- **출력 노치**(선택): N(s) = (s² + 2·0.15·ωr s + ωr²)/(s² + 2·0.7·ωr s + ωr²), ωr = 3.47 Hz. 펌웨어는 쌍선형 변환(중심주파수 프리워핑)으로 구현합니다.
- **출력 포화** [0, 최대 PWM]와 조건부 적분(포화 방향으로는 적분 정지)으로 와인드업을 막습니다.
- **ff**는 운전점 근처의 평형 PWM입니다. 적분이 나머지를 맞춥니다.

### 해석

- **P 제어(목표 4)**: 적분이 없어서 정상상태 오차가 1/(1+Kp·K) ≈ 64%입니다. 이득을 더 올리면 3.5 Hz 공진 때문에 불안정해지므로, P만으로는 오차를 줄일 수 없습니다. 이것이 PI가 필요한 이유입니다.
- **PI(노치 없음)**: Ti = T(플랜트 극점 상쇄)로 두고 Ms ≤ 1.6을 맞추면 Kp가 2.8로 제한되어 느립니다(상승 1.6 s). **이득을 제한하는 것은 진자가 아니라 3.5 Hz 공진**입니다.
- **PI + 노치(권장)**: 공진을 깎으면 같은 강인성(Ms 1.6)에서 이득을 약 3배 올릴 수 있습니다. 상승 0.4 s, 오버슈트 1% 미만이고, K가 0.12–0.21로 바뀌어도 상승 0.22–0.56 s로 무난합니다.
- **D 항은 이득이 거의 없습니다.** 이 플랜트는 저주파에서 이미 강하게 감쇠되어 있어(진자 공진 없음) D가 개선할 게 없습니다. 반면 자이로 진동(약 46 Hz, σ 25 °/s)이 그대로 PWM 잡음으로 들어갑니다. "PID 설계"로 보고할 때는 PID + 노치(Td 작게)를 쓰되, PI와 거의 같다는 점을 결과로 보이면 됩니다.
- **Z-N(목표 6)**: 한계이득 Ku ≈ 11.5 PWM/°, Tu ≈ 0.30 s(3.35 Hz)는 **구조 공진**에서 정해집니다. 그래서 Z-N PID는 Ki가 크고 공진 쪽 여유가 없어, K가 크거나 공진이 10% 낮은 조합에서 **불안정**합니다. 공칭 조건에서도 오버슈트가 15%입니다. 노치를 넣으면 안정해지지만 오버슈트가 23%로 커집니다. Z-N은 플랜트 형태를 고려하지 않고 이득을 정한다는 한계를 이 실험에서 직접 보여 줄 수 있습니다.
- K가 0.21이면 Ku는 8.2로 떨어집니다. 하드웨어 릴레이 시험에서는 Ku ≈ 8–12, Tu ≈ 0.29–0.31 s가 나올 것으로 예상합니다.

## 하드웨어 실험 순서 (lab ⑥ 탭)

1. 실험 직전에 정지 보정과 영점을 잡고, 각도 한계를 기준 + 15° 정도로 낮춥니다(예: 40°).
2. **목표 4**: 프리셋 "P" → 이득 적용 → 폐루프 스텝 20° → 25°. 정상상태 오차를 확인합니다(예측 약 64%).
3. **목표 5**: 프리셋 "PI + 노치" → 같은 스텝. 결과 창에 측정과 모델(K=0.12/0.21) 예측이 겹쳐 그려집니다. 그다음 "PID + 노치"와 비교합니다.
4. **목표 6**: PI + 노치로 유지한 상태에서 릴레이 시험(d = 10–15 PWM) → Ku, Tu → Z-N P/PI/PID 이득을 불러와 스텝 시험. Z-N PID는 처음에 각도 한계를 낮게 두고, 진동이 커지면 바로 STOP.
5. 각 결과 CSV(`aero_CLSTEP_*.csv`, `aero_RELAY_*.csv`)에는 기준(`ref_deg`)과 이득(`# pid` 줄)이 함께 저장됩니다.

## 주의

- ff는 기준 각도의 평형 PWM 근처로 두세요(20°라면 약 145–150). 너무 다르면 시작할 때 적분이 그만큼 채워질 때까지 오차가 납니다.
- 이득은 전원을 켤 때마다 0으로 초기화됩니다(EEPROM에 저장하지 않음). 연결 후 **이득 적용**을 누르세요.
- K가 세션 중 줄어드는 현상(약 20%)은 PI 적분이 흡수합니다. 응답 속도는 K에 비례해 느려집니다.
