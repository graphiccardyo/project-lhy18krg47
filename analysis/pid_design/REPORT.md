## 플랜트

[data/20261113_run1/analysis/REPORT.md](../../data/20261113_run1/analysis/REPORT.md)의 모델입니다(θ ≈ 20°, PWM ≈ 140, 소신호). 폐루프 기록(run2·run3)으로 검증했습니다.

```
P(s) = [ K/(0.319 s + 1) · 17.8²/(s² + 4.85 s + 17.8²)  +  0.05/(6 s + 1) ] · e^(−0.021 s)    [deg/PWM]
```

- 빠른 경로 이득 K는 **공칭 0.14**입니다. 20° 릴레이에서 0.15, 30° 릴레이에서 0.24로, 운전점이 높으면 커집니다.
- **2.84 Hz 구조 공진**(ζ ≈ 0.14)이 있어서 위상이 −180°가 되는 곳(2.77 Hz)이 진자 대역이 아니라 이 공진입니다.
- 느린 경로 0.05/(6 s + 1)은 케이블·크리프로 추정하는 수 초 단위 성분입니다. 적분 동작과 PWM 궤적에 영향을 주고, 안정성에는 거의 영향이 없습니다.
- 강인성은 K ∈ {0.12, 0.14, 0.24} × 공진 주파수 ±10%, 즉 9개 조합의 최악값으로 평가했습니다.

## 제어기 구조 (펌웨어 `pidStep`과 동일)

```
u = ff + Kp·e + Ki·∫e dt − Kd·ω_f        e = 기준 − θ,  Ts = 10 ms
```
- **D는 자이로 각속도**(10 Hz 저역통과)를 **측정값에** 적용합니다. 기준이 바뀌어도 미분 킥이 없고, θ를 미분하지 않아 잡음이 적습니다.
- **출력 노치**(선택): N(s) = (s² + 2·0.15·ωr s + ωr²)/(s² + 2·0.7·ωr s + ωr²), **ωr = 2.84 Hz**. 펌웨어는 쌍선형 변환(중심주파수 프리워핑)으로 구현합니다.
- **출력 포화** [최소 PWM, 최대 PWM]와 조건부 적분(포화 방향으로는 적분 정지)으로 와인드업을 막습니다. `simulate()`에 `umin`, `umax` 인자가 있습니다(기본 0, 255).
- **ff**는 운전점 근처의 평형 PWM입니다(11-13 기구: 20°에서 약 140). 적분이 나머지를 맞춥니다.

### 해석

- **P 제어(목표 4)**: 정상상태 오차 약 68%. 이득을 더 올리면 2.84 Hz 공진 때문에 불안정해집니다.
- **PI(노치 없음)**: Ms ≤ 1.6을 맞추면 Kp가 2.1로 제한되어 느립니다(상승 2.1 s). **이득을 제한하는 것은 진자가 아니라 공진**입니다. 사용자의 손튜닝 PID(Kp 0.9, Ki 7)는 더 보수적이고(최악 Ms 1.21), 실측 상승 1.45–1.51 s를 모델이 1.59 s로 예측했습니다(run3).
- **PI + 노치(권장)**: 공진을 깎으면 같은 강인성에서 이득을 약 2.6배 올릴 수 있습니다. 상승 0.63 s. **노치는 반드시 2.84 Hz로** 두세요. 11-06 권장값(노치 3.47 Hz)은 새 모델의 30° 운전점(K 0.24)에서 Ms 2.2입니다. run2에서 사용자가 쓴 PI 4.5 / 13.5 + 노치 2.85 Hz는 최악 Ms 1.38로 안전한 쪽이었고, 실측 상승 0.73 s였습니다.
- **D 항은 이득이 거의 없습니다.** 11-06과 같은 결론입니다.
- **Z-N(목표 6)**: 한계이득 Ku ≈ 10.8 PWM/°, Tu ≈ 0.365 s(2.74 Hz)는 **구조 공진**에서 정해집니다. 실측 릴레이(run3, 20°)는 Ku 10.2, Tu 0.370 s로 모델과 일치했습니다. Z-N PID는 공칭에서도 Ms 3.9이고 K가 큰 조합에서 불안정합니다. 실측(run3 154019·154046)에서도 30°에서 지속 진동이 생겼습니다. Z-N이 플랜트 형태를 고려하지 않는다는 한계를 실험으로 보인 셈입니다.
- K가 0.24(30° 운전점)이면 Ku는 6.3으로 떨어집니다. run2의 30° 릴레이 실측은 6.24였습니다.

## 하드웨어 실험 순서 (lab ⑥ 탭)

1. 실험 직전에 정지 보정과 영점을 잡고, 각도 한계를 기준 + 15° 정도로 낮춥니다(예: 40°).
2. **목표 4**: Kp 2.85 (Ki = Kd = 0, 노치 끔) → 이득 적용 → 폐루프 스텝 20° → 25°. 정상상태 오차를 확인합니다(예측 약 68%).
3. **목표 5**: PI + 노치(Kp 5.40, Ki 16.9, 노치 **2.84 Hz** / ζz 0.15 / ζp 0.7) → 같은 스텝. 결과 창에 측정과 모델(K = 0.14/0.24) 예측이 겹쳐 그려집니다. 그다음 PID + 노치(Kd 0.092 추가)와 비교합니다. **이 이득은 아직 하드웨어에서 시험하지 않았습니다.**
4. **목표 6**: PI + 노치로 유지한 상태에서 릴레이(d = 10–15 PWM) → Ku, Tu → Z-N 이득으로 스텝. 진동이 커지면 바로 STOP.
5. 각 결과 CSV(`aero_CLSTEP_*.csv`, `aero_RELAY_*.csv`)에는 기준(`ref_deg`)과 이득(`# pid` 줄)이 함께 저장됩니다.

## 주의

- ff는 기준 각도의 평형 PWM 근처로 두세요(11-13 기구에서 20°는 약 140, 30°는 약 200). 너무 다르면 시작할 때 적분이 채워질 때까지 오차가 납니다.
- 이득은 전원을 켤 때마다 0으로 초기화됩니다(EEPROM에 저장하지 않음). 연결 후 **이득 적용**을 누르세요.
- 30°에서는 PWM 200 근처라 최대 PWM 210에 쉽게 닿습니다. 30° 이상 스텝은 최대 PWM을 230–255로 올리거나 기준을 낮추세요.
- 케이블이 걸렸다 풀리는 충격으로 2.7 Hz 진동이 1–1.5 s 생길 수 있습니다(run2·run3). 제어기 불안정과 구별하세요. 시작 순간 PWM이 그대로인데 θ가 튀면 바깥 충격입니다.
