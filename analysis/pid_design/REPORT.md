## 플랜트

[data/20261115_run1](../../data/20261115_run1/analysis/REPORT.md)의 개루프 CHIRP 2회로 맞추고, 느린 경로는 [run2](../../data/20261115_run2/analysis/REPORT.md)의 폐루프 스텝 다섯 기록으로 맞췄습니다(θ ≈ 20°, PWM ≈ 150, 소신호).

```
P(s) = [ 0.164/(0.324 s + 1) · 14.8²/(s² + 2.48 s + 14.8²)  +  0.12/(3 s + 1) ] · e^(−0.024 s)    [deg/PWM]
```

- **2.35 Hz 구조 공진**(ζ ≈ 0.08)에서 위상이 −180°가 됩니다(2.31 Hz). 이득을 제한하는 것은 진자가 아니라 이 공진입니다.
- 30°(PWM ≈ 200)에서는 공진이 2.26 Hz, ζ 0.066으로 더 낮고 약해, 공진 근처 이득이 20°의 1.3–1.4배입니다. 강인성 평가에서는 이것을 K 0.23(공칭 모양의 등가 이득)으로 넣었습니다.
- 느린 경로 0.12/(3 s + 1)은 케이블·크리프로 추정하는 수 초 단위 성분입니다. 폐루프에서 기준을 유지하는 동안 PWM이 흘러내리는 것과 오버슈트를 키우는 것이 이 항입니다.
- 강인성은 K ∈ {0.12, 0.164, 0.23} × 공진 주파수 ±10%, 즉 9개 조합의 최악값으로 평가합니다.
- 검증: 20° 릴레이 실측 Tu 0.439 s · Ku 4.87 vs 모델 0.430 s · 5.01. 폐루프 스텝 θ 적합도 87–91%.

## 제어기 구조 (펌웨어 `pidStep`과 동일)

```
u = ff + Kp·e + Ki·∫e dt − Kd·ω_f        e = 기준 − θ,  Ts = 10 ms
```
- **D는 자이로 각속도**(10 Hz 저역통과)를 **측정값에** 적용합니다. 기준이 바뀌어도 미분 킥이 없고, θ를 미분하지 않아 잡음이 적습니다.
- **출력 노치**(선택): N(s) = (s² + 2·0.15·ωr s + ωr²)/(s² + 2·0.7·ωr s + ωr²), **ωr = 2.35 Hz**. 펌웨어는 쌍선형 변환(중심주파수 프리워핑)으로 구현합니다.
- **출력 포화** [최소 PWM, 최대 PWM]와 조건부 적분(포화 방향으로는 적분 정지)으로 와인드업을 막습니다.
- **ff**는 운전점 근처의 평형 PWM입니다(11-15: 20°에서 약 150, 30°에서 약 200). 적분이 나머지를 맞춥니다.

### 해석

- **P 제어(목표 4)**: 정상상태 오차 약 71%. 이득을 더 올리면 2.35 Hz 공진 때문에 불안정해집니다.
- **PI(노치 없음)**: Ms ≤ 1.6을 맞추면 Kp가 1.2로 제한되어 느립니다(상승 2.5 s). 손튜닝 PID(0.9 / 7)는 Ki가 커서 더 빠르지만(1.2 s) 최악 Ms 1.44로 여전히 안전합니다.
- **PI + 노치(권장)**: 공진을 깎으면 같은 강인성에서 Kp를 약 3.7배 올릴 수 있습니다. 상승 0.56 s, 하드웨어 0.57–0.71 s. **노치는 반드시 공진 주파수(2.35 Hz)에 두세요.** 공진에서 0.5 Hz 벗어난 11-13 설계(2.84 Hz)는 최악 Ms 3.3입니다.
- 노치는 공진에서 제어기가 반응하지 않게 해 이득을 올릴 수 있게 할 뿐, 공진 자체를 감쇠시키지는 않습니다. 외란(진동·케이블)으로 흔들리는 2.0–2.4 Hz 리플은 남습니다.
- **D 항은 이득이 거의 없습니다.** 11-06·11-13과 같은 결론입니다.
- **Z-N(목표 6)**: 한계이득 Ku ≈ 4.9 PWM/°, Tu ≈ 0.43 s(2.31 Hz)는 구조 공진에서 정해집니다. 실측 릴레이(run1)는 Ku 4.87, Tu 0.439 s로 모델과 일치합니다. Z-N PID는 공칭에서 Ms 3.7이고 K가 큰 조합에서 불안정합니다. 하드웨어(11-15 run3)에서도 20–25°에서 2.34 Hz 리플이 지속됐습니다(11-13 run3의 30° 지속 진동과 같은 결론). Z-N이 플랜트 형태를 고려하지 않는다는 한계입니다.
- 실측 릴레이로 계산한 Z-N: P 2.44, PI 2.19 / 5.99, PID 2.92 / 13.3 / 0.160 (모델값과 거의 같음).

## 하드웨어 실험 순서 (lab ⑥ 탭)

1. 실험 직전에 정지 IMU 점검(`python -m rl.imu_check --port COM4`, 1분), 각도 한계를 기준 + 15° 정도(예: 40°)로 낮춥니다.
2. **목표 4**: Kp 1.59 (Ki = Kd = 0, 노치 끔), ff 150 → 폐루프 스텝 20° → 25°. 정상상태 오차 약 71% 예측.
3. **목표 5**: PI + 노치(Kp 4.30, Ki 13.3, 노치 **2.35 Hz** / ζz 0.15 / ζp 0.7) → 같은 스텝(확인됨, run2). 그다음 PID + 노치(Kd 0.067)와 손튜닝 PID 비교.
4. **목표 6**: 릴레이(d = 10–15) → Ku, Tu → Z-N 이득으로 스텝. Z-N PID는 진동이 커지면 바로 STOP.
5. 각 결과 CSV(`aero_CLSTEP_*.csv`, `aero_RELAY_*.csv`)에는 기준(`ref_deg`)과 이득(`# pid` 줄)이 함께 저장됩니다.

## 주의

- ff는 기준 각도의 평형 PWM 근처로 두세요(11-15: 20°에서 약 150, 30°에서 약 200). PWM 200 위에서는 추력이 거의 늘지 않아(PWM 250 ≈ 39°) 30°를 넘는 기준은 여유가 없습니다.
- 이득은 전원을 켤 때마다 0으로 초기화됩니다(EEPROM에 저장하지 않음). 연결 후 **이득 적용**을 누르세요.
- 플랜트가 세션 사이에 변했습니다(11-13 → 11-15: 공진 2.84 → 2.35 Hz). 노치·이득이 공진에 맞는지 의심되면 릴레이 한 번(Tu)으로 공진 근처 주파수를 확인하세요.
- 케이블이 걸렸다 풀리는 충격으로 공진 진동이 1–1.5 s 생길 수 있습니다. 제어기 불안정과 구별하세요. 시작 순간 PWM이 그대로인데 θ가 튀면 바깥 충격입니다.
