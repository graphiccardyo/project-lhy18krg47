## 결론

**이 데이터로는 신뢰할 수 있는 동적 전달함수를 얻을 수 없습니다.** 원인은 모델 차수나 추정 방법이 아니라 각도 측정입니다.

1. **가속도계가 프로펠러 진동에 묻혔습니다.** 모터가 돌면 θ<sub>acc</sub>가 ±150° 범위로 흔들립니다(σ 63–84°). β = 0.301로 가속도 비중이 높아 Madgwick θ가 실제 자세에서 벗어나 떠내려갑니다. 그 결과 자이로 적분각과 최대 11–92° 차이가 나고, 정적 특성 그래프가 단조롭지 않습니다.
2. **자이로도 일부 오염되었습니다.** ω에 약 37 Hz, σ 44–123 °/s의 진동이 실려 있습니다. 같은 조건의 정적 특성 두 번이 절대 각도에서 크게 다르게 나왔습니다(PWM 250에서 55° vs 112°). 두 번째 측정에서는 PWM 80일 때 1.5 s 동안 75°가 한쪽으로 쌓였습니다. 진동이 센서 내부 필터 이전 단계에서 ±500 °/s를 넘어 클리핑된 것(비대칭 → 가짜 직류 성분)으로 추정합니다.
3. **스텝·스윕(PWM 180 ± 12)의 신호 대 잡음비가 낮습니다.** 대역별 SNR은 0.5–5이고, 응답 진폭(약 2–4°)이 잡음과 비슷합니다. 2차 모델을 출력오차로 맞추면 적합도는 15% 미만이고, 실험 간 교차검증(STEP↔CHIRP)은 음수입니다.

## 잠정 모델 (검증되지 않음)

그나마 일관된 두 정보로 만든 모델입니다.

- **정적 기울기**(∫ω 기준, PWM 160–200): 0.202, 0.230 °/PWM → **K ≈ 0.22 °/PWM**. 두 번의 측정이 일치합니다. 절대 각도는 서로 달라도 기울기는 드리프트의 영향을 덜 받습니다.
- **자유 진동**(정적 특성 계단 직후 링잉, 감쇠 정현 맞춤): PWM 70→80에서 ωn = 3.65 rad/s, ζ = 0.11(적합 97%). PWM 120→130에서 ωn = 3.46, ζ = 0.30(76%). → **ωn ≈ 3.5 rad/s (0.56 Hz), ζ ≈ 0.1–0.3**.

```
G(s) ≈ K ωn² / (s² + 2ζωn s + ωn²) ≈ 2.7 / (s² + 1.4 s + 12.3)   [deg / PWM]   (K=0.22, ωn=3.5, ζ=0.2)
MATLAB:  G = tf(0.22*3.5^2, [1 2*0.2*3.5 3.5^2]);
```

이 모델도 스텝·스윕 데이터에 대해 적합도가 음수입니다. 따라서 **PID 설계의 출발점으로만** 쓰고, 측정을 고친 뒤 다시 추정해야 합니다. ζ의 불확실성이 특히 큽니다(0.1–0.47).
