# 2026-11-15 run3 — Z-N PID 하드웨어 시험

[run1](../../20261115_run1/analysis/REPORT.md)의 실측 릴레이(Ku 4.87, Tu 0.439 s)로 계산한 **Z-N PID(2.92 / 13.3 / 0.160)**를 처음으로 실제 이득 그대로 시험했습니다. [run2](../../20261115_run2/analysis/REPORT.md)에서 Z-N PID를 의도한 기록 다섯 개는 Kp 2.19로 적용돼 있었습니다.

**결론: 20° → 25°에서는 발산하지 않지만, 2.34 Hz 공진 리플이 기록 내내 줄지 않고 남습니다(σ 0.34–0.68°). Kp 2.19 조합이나 PI + 노치보다 리플이 크고, 모델 공칭 Ms 3.6에 맞는 작은 여유입니다.** 30°(모델 K 0.23)에서는 모델상 불안정이라 시험하지 않았습니다.

- **안정하지만 공진 감쇠가 작습니다.** 리플이 커지지는 않지만(발산 없음, 스텝 뒤 오히려 0.5 → 0.3–0.4°) 20°(스텝 전·복귀 뒤)에서도 0.4–0.7°로 계속 남습니다. 같은 Ki·Kd에 Kp만 2.19인 조합은 같은 기록 길이에서 0.1–0.2°까지 가라앉습니다. Kp를 2.19 → 2.92로 올리면 공진에서의 루프 이득이 커져 감쇠가 줄어든다는 모델 예측(Ms 5.2 → 불안정 쪽)과 방향이 같습니다.
- **상승은 빠르지 않습니다.** 0.72 s로 PI + 노치(0.57–0.71 s)와 비슷하거나 조금 느리고, 모델(0.56 s)보다 느립니다. 그대로의 오버슈트 23%는 대부분 리플 봉우리이고, 리플을 빼면 4%입니다(모델 13%).
- **모델은 리플을 재현하지 않습니다.** 모델 시뮬레이션에는 잡음·케이블 외란이 없어서, 공진이 약하게 감쇠된 폐루프에서 외란이 계속 리플을 일으키는 모습이 안 나옵니다. θ 적합 81%는 주로 리플 때문입니다. PWM 적합 48%는 유지 PWM이 모델보다 약 10 높게 이어진 오프셋 때문이고(run2보다 2.5시간 뒤라 운전점이 흘렀을 수 있음), 원인은 따로 확인하지 않았습니다.
- **Z-N의 한계(목표 6 결론)**: Z-N PID의 Ku·Tu는 진자가 아니라 2.35 Hz 구조 공진에서 정해져, PM 70°인데도 공진 근처 여유(Ms)가 작습니다. 11-13 Z-N PID(30°에서 2.7 Hz 지속 진동)와 같은 결론을 새 플랜트에서 다시 확인했습니다. 같은 이득에 2.35 Hz 노치를 넣으면 모델 최악 Ms 1.45입니다([pid_design](../../../analysis/pid_design/REPORT.md)).
