# 2026-11-15 run3 — Z-N PID와 Z-N PID + 노치 하드웨어 시험

[run1](../../20261115_run1/analysis/REPORT.md)의 실측 릴레이(Ku 4.87, Tu 0.439 s)로 계산한 **Z-N PID(2.92 / 13.3 / 0.160)**를 처음으로 실제 이득 그대로 시험했습니다. [run2](../../20261115_run2/analysis/REPORT.md)에서 Z-N PID를 의도한 기록 다섯 개는 Kp 2.19로 적용돼 있었습니다. 이어서 같은 이득에 **2.35 Hz 노치**를 넣어 비교했습니다.

**결론**
- **Z-N PID**: 20° → 25°에서 발산하지는 않습니다. 그러나 2.34 Hz 공진 리플이 기록 내내 줄지 않고 남습니다(2 s 창 σ 0.34–0.68°). 모델 공칭 Ms 3.6에 맞는 작은 여유입니다. 30°(모델 K 0.23)는 모델상 불안정이라 시험하지 않았습니다.
- **Z-N PID + 2.35 Hz 노치**: 리플이 절반으로 줄고(유지 σ 0.43 → 0.24°) 기록 내내 0.14–0.28°로 평평합니다. PWM 떨림은 2.0 → 0.8로 줄고, 상승도 빨라집니다(0.72 → 0.60 s). 모델 Ms는 1.18–1.28로 K 범위 전체에서 안정입니다.
- 이득은 그대로 두고 공진 주파수의 루프 이득만 깎았더니 문제가 사라졌습니다. Z-N 이득의 여유 부족은 **구조 공진** 때문이라는 결론이 하드웨어로 직접 확인됐습니다.

0–2 s는 기록 시작 직후의 정착 과도라 빼고 봅니다. 리플 주성분은 세 기록 모두 2.34 Hz이고, 유지 구간에서 2–3 Hz 비중은 76%(Z-N PID), 72%(+ 노치)입니다. 유지 구간 첨두-첨두는 2.2° → 1.3°입니다.

- **Z-N PID: 안정하지만 공진 감쇠가 작습니다.** 리플이 커지지는 않습니다(발산 없음, 스텝 뒤 오히려 0.5 → 0.3–0.4°). 그러나 20°(스텝 전·복귀 뒤)에서도 0.4–0.7°로 계속 남습니다. 같은 Ki·Kd에 Kp만 2.19인 조합은 같은 기록 길이에서 0.1–0.2°까지 가라앉습니다. Kp를 올릴수록 공진에서의 루프 이득이 커져 감쇠가 줄어든다는 모델 예측(Ms 5.2 → 불안정 쪽)과 방향이 같습니다.
- **노치를 넣으면** 스텝 전 20°에서부터 리플이 0.16–0.27°로 작고 시간에 따라 커지지 않습니다. PI + 노치(0.10–0.30°)와 같은 수준입니다. 남는 리플도 2.34 Hz입니다. 노치는 제어기가 공진에 반응하지 않게 할 뿐 공진 자체를 감쇠시키지 않아서, 외란(진동·케이블)이 일으키는 흔들림은 남습니다.
- **상승·오버슈트**: 노치를 넣으면 상승이 0.60 s로 모델(0.58 s)과 맞고, 그대로의 오버슈트가 23% → 14%로 줄어듭니다(리플 봉우리가 작아진 덕분). 리플을 뺀 오버슈트는 4–6%로 둘 다 모델(12–13%)보다 작습니다.
- **모델 적합**: 노치 기록이 θ 89%로 run2 수준입니다. 노치 없는 기록의 θ 81%는 모델에 없는 지속 리플 때문입니다(모델에는 잡음·케이블 외란이 없음). PWM 적합 48–61%는 유지 PWM이 모델보다 높게 이어진 오프셋 때문입니다. run2보다 2.5시간 뒤라 운전점이 흘렀을 수 있지만, 원인은 따로 확인하지 않았습니다.
- **목표 6 결론**: Z-N PID의 Ku·Tu는 진자가 아니라 2.35 Hz 구조 공진에서 정해집니다. 그래서 PM이 70°여도 공진 근처 여유(Ms)가 작습니다. 11-13 Z-N PID(30°에서 2.7 Hz 지속 진동)와 같은 결론을 새 플랜트에서 다시 확인했습니다. 같은 이득에 노치를 넣으면 이 문제가 사라집니다. Z-N 이득 자체가 아니라 공진을 다루지 않는 것이 문제라는 뜻입니다.
