## 3. 전달함수

run B(±25) 주파수응답에 맞추고, 나머지 모든 기록에 시뮬레이션해 검증했습니다(별도 검증 데이터 없이 실험 간 교차검증).

```
G(s) = K · e^(−0.016 s) / (0.328 s + 1) · 21.8² / (s² + 5.37 s + 21.8²)      [deg/PWM]
       공진 fr = 3.47 Hz (ωr = 21.8 rad/s), ζr = 0.12,  시정수 T = 0.33 s,  지연 16 ms (DLPF 21 Hz 지연 약 8 ms 포함)
MATLAB:  G = tf(K*21.8^2, conv([0.328 1], [1 5.37 21.8^2]), 'InputDelay', 0.016);
```

| 검증 기록 | 형태와 K 모두 run B 값 (K=0.131) | 형태 고정, K만 기록별로 맞춤 | 잡음 한계 |
|---|---|---|---|
| run B CHIRP ×2 (추정에 사용) | 79%, 78% | 81%, 80% (K 0.144 / 0.121) | ≈80% |
| run A CHIRP ×2 | 65%, 55% | 65%, 55% (K 0.127 / 0.134) | ≈58% |
| run2 CHIRP ×2 (15분 전) | 56%, 64% | 59%, 68% (K 0.155 / 0.159) | ≈66% |
| run2 STEP ×2 (20분 전) | 46%, 17% | 77%, 36% (K 0.205 / 0.188) | ≈63% |

- **형태(T, 지연, 공진)는 모든 실험에서 일관됩니다.** K만 맞추면 모든 기록이 각자의 잡음 한계 근처까지 맞습니다. 이 형태를 확정 모델로 봐도 됩니다.
- 주파수응답 오차 9%, 0.12–7 Hz에서 크기·위상 모두 일치(`model_fit.png` 위쪽).
- 0.12 Hz 미만에서는 Madgwick θ와 자이로 적분각의 위상이 다르게 나옵니다(−21° vs −1°). Madgwick의 느린 가속도 보정이나 드리프트에 의한 측정 쪽 효과로 보고 모델에 넣지 않았습니다.

## 4. 문제: 이득 K가 시간에 따라 줄어듦

| 시각 | 기록 | K [°/PWM] | PWM 150 정착 각도 |
|---|---|---|---|
| 14:16–14:18 | run2 STAIR | (정적 기울기 0.19–0.21) | 21.6–21.9° |
| 14:18–14:19 | run2 STEP | 0.19–0.21 | 22.3–23.4° |
| 14:19–14:22 | run2 CHIRP | 0.155–0.159 | 23.5–23.9° |
| 14:34–14:35 | run A | 0.127–0.134 | 20.0–20.9° |

- 20분 사이에 같은 PWM 150에서 **정착 각도가 약 3°, 이득이 약 20% 줄었습니다.** 추력이 약해졌다는 뜻입니다. **모터 전원 전압 강하**(배터리 소모, 전원장치 전류 제한)나 **모터 발열**을 의심합니다. 입력을 PWM으로 쓰므로 전원 전압이 바뀌면 플랜트 이득이 그대로 바뀝니다.
- 같은 시각대에서도 스텝(0.19–0.21)이 스윕(0.155)보다 큽니다. 한 방향으로 올리는 입력(스텝·계단)과 양방향으로 흔드는 입력(스윕)의 차이로 보이며, 피벗 마찰 같은 작은 비선형이 원인일 수 있습니다.

## 5. PID 설계에 주는 의미

- **K 범위 0.12–0.21 °/PWM** (공칭 약 0.15). 안정성은 큰 쪽(0.21), 성능은 작은 쪽(0.12)으로 검토하세요.
- **위상 −180° 교차 3.38 Hz, 그때 |G| ≈ 0.076 °/PWM** (K=0.131 기준). 순수 P 제어라면 이득 한계가 약 13 PWM/°이고, K=0.21이면 약 8 PWM/°입니다.
- 3.5 Hz 공진 때문에 **폐루프 교차주파수는 약 1 Hz 이하**로 잡으세요. D 항은 공진을 증폭하므로 미분 필터(예: 10–15 Hz 1차)를 쓰고, 필요하면 3.5 Hz 노치 필터를 고려하세요.
- Z-N 방법(목표 6): 이 플랜트는 순수 P로 진동 한계에 도달하는 주파수가 약 3.4 Hz, 즉 구조 공진입니다. Ku/Tu가 진자 동특성이 아닌 공진으로 정해지므로, Z-N 결과는 공격적으로 나올 수 있습니다. 실험할 때 주의하세요.
