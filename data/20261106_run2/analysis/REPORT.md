## 3. 동적 응답 (시험 2)

- **스텝**: +12 PWM에 약 1 s 안에 **오버슈트 없이** Δθ ≈ 2.1–2.6°로 올라갑니다(과감쇠). 정상상태 이득은 0.17–0.21 °/PWM입니다.
- **주파수응답**(스윕 사인 2회, 기록 간 차이 대부분 3–15%):

| f [Hz] | 0.10 | 0.20 | 0.38 | 0.60 | 0.94 | 1.47 | 2.29 | 2.86 |
|---|---|---|---|---|---|---|---|---|
| \|G\| [°/PWM] | 0.165 | 0.145 | 0.119 | 0.101 | 0.076 | 0.060 | 0.065 | 0.084 |
| 위상 [°] | −23 | −32 | −38 | −54 | −69 | −90 | −111 | −142 |

  0.1–1.5 Hz에서는 1차 지연과 비슷한 모양이고, **진자형 공진 봉우리는 없습니다**(이 운전점에서는 진자가 강하게 감쇠됨). 2 Hz 위에서는 이득이 다시 오르고 위상이 빨리 떨어집니다. **약 3 Hz 이상에 다른 모드**(막대·구조 진동 등)가 있을 수 있습니다.
- 정적 특성 계단 직후의 "링잉" 맞춤(ζ≈0.4–0.55, ωn≈2.2–2.7)은 스텝·주파수응답과 맞지 않습니다(주파수응답 오차 85–107%). 계단 직후의 진동 잡음을 감쇠 정현으로 잘못 맞춘 것이므로 쓰지 않습니다.

## 4. 전달함수 추정 (시험 3, 별도 검증 데이터 없이)

스텝 2개와 스윕 2개 모두를 대상으로, **기록 하나를 빼고 추정한 뒤 뺀 기록에 비교하는 교차검증**을 했습니다.

| 모델 구조 | 교차검증 적합도 (CHIRP₁, CHIRP₂, STEP₁, STEP₂) | 평균 |
|---|---|---|
| 1차 + 지연 | 44, 43, 65, 32 % | **46.1 %** |
| 2차 (실극점 2개) + 지연 | 43, 43, 66, 32 % | 46.1 % (두 번째 극점이 사라져 1차와 같음) |
| 2차 (복소극점 허용) + 지연 | 43, 43, 66, 32 % | 46.1 % (ζ→4, 과감쇠로 수렴) |
| 영점 + 극점 2개 + 지연 | 42, 43, 66, 35 % | 46.6 % (느린 성분 τ≈6 s, 개선 미미) |

차수를 올려도 교차검증이 좋아지지 않으므로 **1차 + 지연**을 채택합니다. 느린 성분(τ≈6 s)은 두 번의 스텝에서 크리프 방향이 반대로 나왔습니다(θ: 0.00° / +0.29°, ∫ω: −0.75° / +0.53°). 따라서 물리적인 응답이 아니라 **±0.5–1°의 저주파 드리프트**로 판단합니다. 잡음 상한(63–66%)과 실제 적합도(46%) 사이의 차이는 대부분 이 드리프트 때문입니다(STEP₂는 하강 후 +0.8°에 머묾).

### 추정 모델 (운전점 PWM ≈ 150, θ ≈ 22°)

```
G(s) = Δθ(s)/ΔPWM(s) = 0.174 · e^(−0.025 s) / (0.341 s + 1)     [deg / PWM]
     = 0.510 · e^(−0.025 s) / (s + 2.93)
MATLAB:  G = tf(0.174, [0.341 1], 'InputDelay', 0.025);
```

| 파라미터 | 값 | 불확실성 / 근거 |
|---|---|---|
| 정상상태 이득 K | 0.174 °/PWM | **0.17–0.21** (스윕 저주파 0.16, 스텝 0.17–0.21, 정적 기울기 0.19–0.21) |
| 시정수 T | 0.34 s (극점 −2.9 rad/s, 0.47 Hz) | 교차검증 모델 간 0.34–0.35 s |
| 지연 L | 25 ms | 20–50 ms |
| 유효 대역 | 0.1–1.5 Hz | 2 Hz 이상 미모델 동특성 가능 |

## 5. 평가 요약

- **사용 가능**: 진동 대책 후 데이터는 재현성이 좋고(상관 0.87–0.95), 정적 특성·스텝·주파수응답이 서로 일관됩니다(이득 0.17–0.21 °/PWM).
- **모델 신뢰도는 보통**: 교차검증 적합도 46%(잡음 상한 약 65%). PID 설계에는 충분하지만, 이득을 ±10–15% 불확실한 것으로 보고 강인하게 설계하세요(예: K = 0.17과 0.21 둘 다로 폐루프 검토).
- **이 운전점(PWM 150)에서만 유효한 소신호 모델**입니다. 정적 특성 기울기가 PWM 160–200에서는 0.15–0.18로 조금 작아지므로, 다른 각도에서 제어하려면 그 운전점에서 다시 식별하세요.

## 6. 다음 실험에서 개선할 것

1. **영점 다시 잡기**: 시작 각도가 +2.4~5°입니다. 실험 직전에 "정지 보정 + 영점"을 하세요.
2. **가진 진폭 키우기**: ±12 → ±25 PWM으로 키우면 SNR이 약 4배가 됩니다(선형 범위는 정적 특성상 PWM 125–175 정도에서 무난함).
3. **드리프트 줄이기**: 시험 시간을 줄이거나(스윕 30–40 s) 반복 횟수를 늘려 평균하세요. 정지 상태 θ가 몇 분 동안 얼마나 떠내려가는지도 한 번 기록해 두면 좋습니다.
4. **2 Hz 이상 확인**: 폐루프 대역을 1 Hz 넘게 잡을 계획이면 0.5–5 Hz 스윕을 따로 해서 3 Hz 부근 모드를 확인하세요.
5. 센서 진동 절연은 여전히 권장합니다(θ<sub>acc</sub> ±25°, 자이로 진동 약 46 Hz).
