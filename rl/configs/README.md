# RL 설정 파일

`python -m rl.train --config <파일>`에 주는 JSON입니다. 바꿀 항목만 적고, 나머지는 `rl/config.py` 기본값을 씁니다. `_`로 시작하는 키(`_comment`)는 무시됩니다.

| 파일 | 내용 |
|---|---|
| `motor2.json` | 11-16 모터 교체 뒤 **잔차 RL** 설정. 아래 표 참고. RL 펌웨어 **AEROPEND_RL 1.2** 필요(잔차가 노치를 통과; 학습기가 버전을 확인) (`scripts/Build-Rl.ps1 -Upload`) |

`motor2.json`의 항목:

| 항목 | 값 | 근거 |
|---|---|---|
| 구조 | **잔차 RL** (`rl.res_max` 15): 보드가 PI + 노치를 매 샘플 계산하고, 정책은 그 출력에 더할 잔차 ±15 PWM을 보냄. 행동 0 = 순수 PID | 순수 RL은 가짜 보드에서 PI + 노치보다 RMS 20–46% 나빴고, 잔차 ±15는 2–4%, ±25는 5–8% (RL_HISTORY D13) |
| 기준선·복귀 PID | PI + 노치 4.30 / 13.3, 노치 2.35 Hz | 새 모델에서도 최악 Ms 1.57 ([data/20261116_run2](../../data/20261116_run2/analysis/REPORT.md) §4) |
| 가짜 보드 플랜트 | 정적 지도 `STATIC_MAP_1116`, K 0.192 · T 0.357 s · L 23 ms · 2.57 Hz / ζ 0.15 · Ks 0.06 / Tc 5 s, 도메인 랜덤화 범위 | 같은 REPORT §3 |
| PWM 상한 | 230 (`LIM`, `RL u_hi`) | 새 모터 보호. 30° ≈ PWM 186 |
| 가동 / 휴식 | 120 s / 90 s | 새 모터 보호 |
| 망 | 16-16 | 보드 위 추론(시연)과 떨림 감소 |
| 휴식 중 추가 갱신 | `utd_rest` 3 | 모터가 멈춘 동안 데이터 재사용 |
| CAPS | `caps_t` 0.3, `caps_s` 0.3 | 정책 출력 매끄러움 (가짜 보드에서 PWM 떨림 −30%) |
| 목표 엔트로피 | −0.5 (기본 −1) | 11-17 rl4에서 α가 0.0017까지 내려가 정상상태 근처를 거의 탐색하지 않음 (행동 곡선 \|a\|² 때문에 0 근처 잔차 잡음 0.1 PWM). −0.5 = σ ≈ 0.15 |
| 자세 감시 | 정지 5° / 경고 3° (기본 3° / 2°) | 새 모터는 PWM 165 위(≈30°)에서 θacc 잡음 σ 13–18°, θ − θacc 평균 −1.3 ~ −2° (자이로 표류 아님: 정지 시 −0.02°, PWM 내리면 바로 0). PI + 노치 복귀 과도에 순간 −4 ~ −6°. 3°에서 rl1·rl2가 시작 10 s 만에 멈춤 (11-17). 예전 폭주(3 → 20 → 43°)는 5°로도 잡힘 |
| 끈 보상·보조 | 고정 적분 보조 `ki_assist` 0, Δ행동 벌점 `w_ddu` 0, 정밀 항 `w_fine` 0 | 적분은 PID가, 떨림은 CAPS가 맡음. 남은 보상 = 오차² + \|오차\| + 잔차 크기 벌점 `w_du` 0.05 |

가짜 보드 사전학습 → 실기:
```
python -m rl.train --fake --fast --randomize --config rl/configs/motor2.json --episodes 150
python -m rl.train --port COM4 --config rl/configs/motor2.json --init data/20261116_sim1
```
`data/20261116_sim1`은 이 설정(잔차 ±15, 시드 0)으로 150 ep 사전학습한 실행입니다(best = ep 120, 버퍼·에피소드 CSV는 빼고 복사).
`--init`은 사전학습 실행의 크리틱·α와 액터 스냅샷(기본 `best`)을 이어받습니다. 버퍼는 비우고, 무작위 워밍업 없이 시작합니다.
